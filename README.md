# FUKUYORI SOFTWARE website

Nor Fukuyori / SPUMONI.ORG の公開アプリを案内する、ビルド不要の静的サイトです。

- 日本語: `index.html`
- English: `en/index.html`
- 共通スタイル: `styles.css`
- アプリ一覧データと操作: `site.js`
- 実際のリポジトリから取得した画像: `assets/`

ローカル確認は、このディレクトリで任意の静的HTTPサーバーを起動して行います。
GitHub Pagesへはリポジトリのルートをそのまま公開できます。

アプリの追加・バージョン変更・説明文変更は、`site.js` 冒頭の `apps` 配列を日本語・英語まとめて更新してください。
